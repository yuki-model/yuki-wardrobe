【GitHubへの更新方法】
1. GitHubの yuki-wardrobe リポジトリを開く
2. Add file → Upload files
3. index.html、style.css、script.js と images フォルダー内の3枚をアップロード
4. 同名ファイルは上書きされます
5. Commit changes を押します
6. Cloudflareが自動で更新します

imagesフォルダーを含めてください。
