YUKI'S WARDROBE VERSION 5 — FINAL

追加内容
・お気に入りに選んだ衣装写真を1枚のコーディネートボードに配置
・各カードにカテゴリー、衣装名、番号、色、柄を表示
・クライアント名、案件名、撮影日、メモをボードに反映
・コーディネートボードをA4 PDFとして保存可能
・送信用文章をコピー可能
・実際の着用合成ではなく、選択写真を並べる無料で安定した方式

使い方
1. 衣装一覧で♡を押して候補を選びます
2. 「候補一覧を見る」を開きます
3. お名前、案件名、撮影日、メモを入力します
4. 「コーディネートボード」を押します
5. 「印刷・PDF保存」を押します
6. 印刷画面でプリンターを「PDFに保存」に変更します

GitHub更新方法
1. yuki-wardrobe リポジトリを開く
2. Add file → Upload files
3. VERSION 5の中身をアップロード
4. Commit changes
5. Cloudflareの自動更新を待ちます
